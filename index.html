Write. That's it.

abstract is a minimal notes editor that treats your notes as what they are: plain .md files in real folders, on your disk. No accounts, no sync daemon, no proprietary format — the folder is the app.

The essentials. Only.

Everything you need to think in text — and nothing that gets in the way.

  • 01

    Spaces are real folders

    Each space is a directory on your disk. Keep several, switch from the sidebar, open any folder with ⌘O.

  • 02

    Plain markdown

    Every note is an ordinary .md file. Open it in anything else, forever.

  • 03

    Autosave

    Writes are debounced as you type. A file is created on the first keystroke and named after its first heading.

  • 04

    GPU-rendered

    Written in Rust on GPUI. Opens instantly, scrolls smoothly, weighs a few megabytes.

  • 05

    Wiki-links & backlinks

    [[note]] links with autocomplete. ⌘-click follows (creating the note if missing); a panel lists what links here.

  • 06

    External-edit aware

    The space folder is watched live. Edit or delete from another app and it shows up instantly.

  • 07

    Session restore

    Reopens your notes, window geometry and sidebar state exactly where you left them.

  • 08

    Chromeless

    Custom titlebar, monochrome themes, first-run tour. Interface in English and Portuguese.

  • 09

    Cross-platform

    Linux (Wayland & X11), macOS and Windows. Bundled Noto fonts for identical rendering everywhere.

Install.

Prebuilt artifacts on every GitHub release. Or build from source in one command.

macOS

abstract-<version>-macos-aarch64.app.zip or x86_64. Ad-hoc signed: right-click → Open on first launch, or

xattr -dr com.apple.quarantine abstract.app

Linux

Tarball, .deb, or the AUR on Arch / CachyOS:

paru -S abstract-editor-bin
sudo dpkg -i abstract-editor_<version>_amd64.deb

Windows

abstract-<version>-windows-x86_64.zip, icon embedded in the .exe. Unzip and run.

From source

Rust toolchain pinned via rust-toolchain.toml.

git clone https://github.com/fireflylabss/abstract
cd abstract && cargo build --release

Open. Write. Close.
