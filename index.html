Sem banco de dados. Sem sincronização obrigatória. Sem formato próprio. Uma nota é um arquivo. Uma pasta é um espaço. Nada mais.

O essencial, e só.

  • 01

    Espaços são pastas reais

    Cada espaço é uma pasta no seu disco. Abra qualquer outra com CtrlO.

  • 02

    Markdown puro

    A primeira linha vira o título — e o nome do arquivo. Tudo é .md comum.

  • 03

    Salvamento automático

    Tudo é salvo sozinho. Apagar envia pra Lixeira, nunca pro nada.

  • 04

    Acelerado por GPU

    Escrito em Rust com GPUI. Abre instantâneo, rola a 120 fps, pesa poucos megas.

  • 05

    Claro, escuro ou sistema

    Paleta monocromática. Alterne com CtrlShiftL.

  • 06

    Modo foco

    Esconda a barra lateral com Ctrl\. Só você e o texto.
