# abstract-website

Landing page do [Abstract](https://github.com/horizzon3507/abstract-editor).

Vite + TypeScript + [motion](https://motion.dev). Sem framework.

```sh
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
```

Deploy: qualquer host estático (`dist/`). O workflow em `.github/workflows/pages.yml` publica no GitHub Pages.
