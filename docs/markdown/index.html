Markdown.

Live rendering powered by tree-sitter: the syntax hides itself until your selection touches it.

Live rendering

abstract shows the rendered note and the markdown source in one place. Markers like **, # and [[ ]] are hidden while you read and come back on the line your cursor or selection is on, so you can always edit the exact characters. What is saved is plain markdown that any other editor can open.

On Linux and Windows, use Ctrl instead of ⌘. Each formatting shortcut wraps the current selection in its markers.

Tasks & code

Click a checkbox to toggle it. The file keeps a plain - [x], and finished tasks are struck through. Fenced code blocks get syntax highlighting when you name the language:

```rust
fn main() {
    println!("hello");
}
```

Highlighted languages: Rust, JavaScript and TypeScript, Python, Go, C and C++, shell, JSON, YAML and TOML. Other blocks still render in a monospace box.

Callouts

Start a block quote with a type in brackets to get a tinted box with a title. Paragraph → Callout in the right-click menu toggles one.

> [!tip] Keep it monochrome
> One accent color competes with the text.

Images & attachments

Paste an image from the clipboard or drop one onto the editor. abstract copies it into an attachments/ folder next to the note and inserts a relative link such as ![](attachments/image-1790692154123.png). Insert → Image… opens a file picker instead.

  • ![alt](path) resolves relative to the note.
  • ![[image.png]] also looks in the note's attachments/, the space root and the root's attachments/.
  • Remote https:// images are not downloaded. The editor never goes online to render a note.
  • Dropped files that are not images become links, and a dropped note from the same space becomes a [[wiki-link]].

Tables

Tables and footnotes land in the release after v0.1.2.

GitHub-style pipe tables render as a monospace block with dimmed pipes, so columns line up. Tab and ⇧Tab realign the columns and move to the next or previous cell, and Tab in the last cell adds a row. Insert → Table adds a two-column table.

Footnotes

Write [^1] in the text and [^1]: The source. anywhere below. The reference shows as [1], and ⌘-click jumps between it and its definition. Insert → Footnote adds the next number and puts the definition at the end of the note.

The right-click menu

Everything above is also in the editor's context menu, next to cut, copy, Paste as plain text (⌘⇧V), Add note link, Add external link and Search for selection.
