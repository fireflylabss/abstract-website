Search.

One palette to find any note in the space, and a find bar for the note in front of you.

Search the space

Press ⌘P or ⌘⇧F (Ctrl on Linux/Windows), or click the magnifier in the toolbar. Results match note titles and the text inside notes, with a snippet for body matches. ↑/↓ move, Enter opens, Esc closes.

Recent notes

With an empty query, the palette lists the notes you edited most recently, so ⌘P Enter jumps back to what you were just working on.

To search for something already on the page, select it and choose Search for selection from the right-click menu.

Find in a note

Find & replace lands in the release after v0.1.2.

⌘F opens the find bar above the note. If text is selected, it becomes the query. Every match is highlighted, and the bar shows which one you are on.

  • Enter goes to the next match and ⇧Enter to the previous one. F3 / ⇧F3 (⌘G / ⌘⇧G on macOS) work from the editor too.
  • Search ignores case by default. The case button next to the query makes it case-sensitive.
  • Esc closes the bar.

Replace

Open the find bar with replace using CtrlH on Linux/Windows or ⌘⌥F on macOS. In the replace field, Enter replaces the current match and moves on, and ⌘Enter replaces them all. Replace all is a single step, so one ⌘Z brings everything back.
