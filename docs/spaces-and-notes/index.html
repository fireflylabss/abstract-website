Spaces & notes.

A space is a directory. A note is a file. Everything else follows from that.

Spaces

Each space is a folder on your disk. Keep several — work, personal, one per project — and switch between them from the space name at the top of the sidebar, or with ⌘O (CtrlO on Linux/Windows). Open folder as space… adds a new one. Links, backlinks and search all work within the active space.

The sidebar

The sidebar is the folder's real tree. Folders expand in place, and the count next to Notes is the number of notes in the space. Hidden files (names starting with .) and symlinked folders are skipped. The + and folder buttons at the top create a note or a folder, and ⌘\ hides the whole sidebar.

Moving things

Drag a note or folder onto another folder, or onto the Notes header to move it to the top level. When a note moves, its relative image paths are rewritten so pictures keep showing.

Creating & naming notes

Press ⌘N for a note or ⌘⇧N for a folder. A note's file is created on the first keystroke and named after its first heading:

  • Characters that are not allowed in file names (/ \ : * ? " < > |) are dropped, and names stop at 80 characters.
  • If the name is taken, abstract adds a number: Ideas.md, Ideas 2.md.
  • While the file name still matches the heading, editing the heading renames the file. Give the file a different name and it stops following.

Rename with F2, from the sidebar menu, or by editing the title. Every [[link]] to the note is updated across the space. See Links & backlinks.

Saving

Writes are debounced as you type and each save replaces the file atomically, so a crash never leaves half a note behind. ⌘S writes immediately. The word count in the toolbar opens Note details: save state, words, characters, reading time, the selection's word count, when the file last changed, and buttons to reveal or copy its path.

Deleting

⌘⇧⌫ (CtrlShiftBackspace), the trash button in the toolbar, or Move to Trash in the sidebar sends the file to the system trash. Nothing is erased for good, so you can restore it from Trash or Recycle Bin.

External edits

The space folder is watched live (inotify on Linux, FSEvents on macOS, ReadDirectoryChanges on Windows). Edit, rename or delete files in Finder, another editor, a script or a sync client and the tree and the open note update right away. Any tool that syncs plain files can sit alongside it.

Session restore

Quit and reopen and you are back where you were: the same space and note, the cursor and scroll position, the window size and position, and whether the sidebar was open.

Where abstract keeps its own files

Nothing is written inside your notes folder except your notes and their attachments. abstract's own state is a few key = value text files:

FileLinux / macOSWindows
Settings (theme, language, updates, tour)~/.config/abstract/settings%APPDATA%\abstract\settings
List of spaces~/.config/abstract/spaces%APPDATA%\abstract\spaces
Session (window, open note, cursor)~/.local/state/abstract/session%LOCALAPPDATA%\abstract\session
Starter space~/.local/share/abstract/Pessoal%APPDATA%\abstract\Pessoal

On Linux and macOS, XDG_CONFIG_HOME, XDG_STATE_HOME and XDG_DATA_HOME override these locations.
