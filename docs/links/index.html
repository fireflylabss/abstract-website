Links & backlinks.

Wiki-style links between the notes in a space, stored as plain text you can read anywhere.

Wiki-links

Type [[ and start a note's name. A list of matching notes opens under the cursor: ↑/↓ to choose, Enter to accept, Esc to close.

  • [[Launch checklist]] links by note name, without the .md, wherever the note lives in the tree.
  • [[Launch checklist|the checklist]] shows the checklist as the link text.
  • Right-click → Add note link turns the selection into [[…]]. In the sidebar, Copy note link copies a ready-made link.

Following a link

⌘-click a wiki-link (Ctrl-click on Linux/Windows) to open the note. If no note has that name yet, abstract creates one with the name as its heading and opens it, so you can link first and write later.

Backlinks

Under every note, Referenced by lists the notes that link to it. Click one to open it. Nothing to configure and no index to rebuild: the list comes from the files in the space.

Renaming keeps links working

Rename a note with F2, from the sidebar, or by changing its heading, and every [[old name]] in the space becomes [[new name]]. Aliases are kept. If two notes share a name, abstract leaves the links alone rather than guess which one you meant.

External links

Select text and press ⌘K to turn it into [text](url). Like every other marker, the URL part hides until the cursor is on the line.
