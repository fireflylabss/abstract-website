Links & backlinks.

Wiki-style linking between the notes in a space.

Wiki-links

Type [[note]] to link to another note. Autocomplete suggests existing notes as you type the name.

Following a link

Ctrl/⌘-click follows a wiki-link. If the target note does not exist yet, it is created for you.

Backlinks

A backlinks panel under every note lists the notes that reference it — nothing to configure and no index to rebuild.
