abstract docs.

A minimal, local-first markdown notes editor, GPU-rendered with GPUI. Your notes are plain .md files in real folders on disk — no accounts, no sync daemon, no proprietary format. The folder is the app.

Where to start

  • Install — downloads for macOS, Linux and Windows, and how updates work.
  • Getting started — open a folder and write your first note.
  • Spaces & notes — folders, files, the sidebar and what lives on disk.
  • Markdown — everything that renders, from tasks to callouts, tables and images.
  • Links & backlinks — [[wiki-links]] and how renames keep them working.
  • Search — the palette across the space, and find & replace in a note.
  • Themes — light, dark, system, and the interface language.
  • Keyboard — every shortcut, per platform.
  • Build from source — toolchain, dependencies and checks.

How it works

  • A space is a folder. Open any directory and abstract shows it as a tree. There is no import step and no database.
  • A note is a file. Each note is a .md file named after its first heading, saved as you type.
  • Markdown stays markdown. Syntax renders in place and only shows while your cursor is on it. What is on disk is what you typed.
  • Other apps are welcome. The folder is watched, so edits from another editor, a script or a sync client show up at once.

What is on disk

A space is exactly what you see in your file manager. Pasted images go into an attachments/ folder next to the note that uses them.

Studio/
├── Welcome.md
├── Journal/
│   └── 2026-09-29.md
└── Projects/
    ├── Launch checklist.md
    ├── Website redesign.md
    └── attachments/
        └── moodboard.png

abstract's own settings, the list of spaces and the last session are small text files kept outside your notes. Spaces & notes lists where.

Built with

abstract is written in Rust on GPUI, parses markdown with tree-sitter, and ships bundled Noto Sans and Noto Sans Mono so it renders the same on Linux, macOS and Windows. It is licensed under Apache-2.0, and the interface is available in English and Portuguese.
