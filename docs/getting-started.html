Getting started.

From zero to a saved note in under a minute.

Open a folder

abstract works on folders, not accounts. On first launch, open any directory — an existing notes folder or an empty one. That folder becomes a space. Press ⌘O (CtrlO on Linux/Windows) to switch spaces later.

Write your first note

Press ⌘N and start typing. The file is created on the first keystroke and named after the note's first heading. Writes are debounced — there is no save dialog, though ⌘S forces a write.

Take the tour

Press F1 any time for the first-run tour. Enter/→ advances, ← goes back, Esc skips.

Make it yours

Cycle the light/dark/system themes with ⌘⇧L, and hide the sidebar with ⌘\ when you want to focus.
