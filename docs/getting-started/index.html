Getting started.

From zero to a saved, linked note in a couple of minutes.

Install

Grab the build for your system from the Install page. On macOS, Gatekeeper may ask for one extra click on the first launch.

Open a folder

abstract works on folders, not accounts. On first launch it opens a starter space called Pessoal in ~/.local/share/abstract/ (%APPDATA%\abstract\ on Windows). To use your own notes, click the space name at the top of the sidebar and choose Open folder as space…, or press ⌘O (CtrlO on Linux/Windows).

You can also pass a folder on the command line, which opens it as the active space:

abstract ~/Documents/notes

Write your first note

Press ⌘N and start typing. Begin with a heading:

# Weekly plan

- [ ] Draft the release notes
- [ ] Review **the docs**

The file is created on the first keystroke and named after the first heading, so this note becomes Weekly plan.md. Change the heading later and the file follows it. There is no save button: writes happen a moment after you stop typing, and ⌘S forces one.

Format as you type

Markdown renders in place. Bold turns bold, checkboxes become clickable and code blocks get highlighted. The markers reappear only on the line your cursor is on. See Markdown for everything that renders.

Link two notes

Type [[ and start a note's name. Pick it from the list, then ⌘-click the link to jump there. The target note now shows your note under Referenced by. More in Links & backlinks.

Find it again

Press ⌘P and type any word from a title or body. With an empty query the palette lists what you edited last. See Search.

Take the tour

The first launch shows a six-step tour that points at the space switcher, the new note and folder buttons, the editor, autosave, the theme toggle and focus mode. Press F1 to see it again.

Make it yours

Cycle the system, light and dark themes with ⌘⇧L or the sun button in the toolbar. Hide the sidebar with ⌘\ when you want only the page. Both choices, like everything else in abstract, are remembered next time.
